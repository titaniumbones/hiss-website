# Website for Humanities and Interpative Social Sciences Hub

Greenfield project to create a new website for the Humanities and Interpretive Social Sciences Research Hub. This is a new initiative to foster cross-disciplinary community for faculty at the University of Toronto's Scarborough campus, primarily for faculty of the six founding departments: Anthropology, Department of Language Studies, English, Geography, Historical and Cultural Studies, and Arts, Culture, and Media.

## Technical Requirements

### Style

Follow University of Toronto typography and color guidelines. Use a proper stylesheet (SASS or PostCSS), setting variables as appropriate. Use the UTSC logo.

### Platform

Use markdown for page content, and next.js as a CMS. Deploy to netlify from github or from the command line. Ensure that Pull Requests to main branch trigger a dev deployment.
